# 日迹 · Financezerone

基于日历的本地记账软件。记录每日开销、管理收支和预算，支持 USD／CNY 原币统计及手动汇率折算。

## 启动

安装 Node.js 20 或更新版本，在项目目录执行：

```sh
npm start
```

打开 http://localhost:4173 。无需安装第三方依赖，无构建步骤，`dist/` 就是可编辑的网页源文件。

## 功能

- 日历收支、每日开销预设、完整记账与快捷收入／支出录入。
- 条目详情侧栏、编辑、删除、撤销，明细搜索与类型／币种筛选。
- 每笔交易独立币种；统计支持原币和统一手动汇率折算。
- 月预算、进度圆环、分类占比、热力格及每日支出／收入／收支图。
- 多套配色、本地字体、响应式布局与过渡动画。
- JSON 账本导入导出、同源浏览器标签页同步。

数据保存在当前浏览器当前网址的 localStorage，不上传服务器。清除浏览器数据会删除账本，请定期导出。当前 JSON 备份包含记录和预设，不包含预算、汇率及界面偏好。

## 可选工作台

复制 `hub/apps.example.json` 为 `hub/apps.json`，填写外部 UWMaster 路径和 Python 路径后，运行 `npm run hub`，打开 http://127.0.0.1:4180 。Windows 也可双击 `打开个人工作台.cmd`。

UWMaster 本身不包含在仓库中，单独运行记账不需要它。本机配置和日志不入库。
